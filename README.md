### IPSOS

IPSOS — это учебная 32-битная операционная система, написанная с нуля на NASM и C.

Проект создан для изучения низкоуровневого программирования, архитектуры x86, работы с железом и построения собственной файловой системы.

## Текущие возможности

    Загрузчик: Собственный MBR (Real Mode -> Protected Mode), загружающий ядро с диска.

    Ядро: Настроены GDT, IDT, PIC (перепрограммирован на 0x20).

    Драйверы:

        VGA (текстовый режим 80x25, обработка \n и \b).

        Клавиатура (PS/2, IRQ1).

        ATA PIO (чтение и запись секторов, LBA28).

    Файловая система (SFS): Собственная простая ФС (Simple File System). Поддерживает создание, чтение, удаление и листинг файлов.

    Оболочка (Shell): Интерактивный терминал с парсером команд.

        ls — список файлов.

        cat <file> — чтение файла.

        write <file> <text> — запись текста в файл.

        rm <file> — удаление файла.

## Технологический стек

    Языки: C (стандарт C99), NASM (ассемблер).

    Компилятор: i686-elf-gcc (кросс-компилятор).

    Эмуляция: QEMU.

    Отладка: GDB.

## Структура проекта
```text

src/
├── boot/       # Загрузчик (MBR)
├── cpu/        # Прерывания (IDT, PIC)
├── drivers/    # Драйверы железа (VGA, ATA, Keyboard)
├── fs/         # Файловая система (SFS)
├── include/    # Заголовочные файлы (.h)
├── kernel/     # Точка входа в C (kernel.c, kernel.asm) и оболочка (shell.c)
└── libs/       # Своя мини-библиотека (strcmp, strlen и т.д.)
 ```

### Как собрать и запустить

## Требования

    nasm

    i686-elf-gcc (кросс-компилятор)

    qemu-system-x86_64

    make

## Сборка
```bash
make all
```

Эта команда соберет загрузчик и ядро, создаст образ диска ipsos.img и запишет туда все необходимые сектора.

## Запуск
```bash
make run
```

(Или вручную через QEMU: qemu-system-x86_64 -drive file=ipsos.img,format=raw,if=ide,index=0)
