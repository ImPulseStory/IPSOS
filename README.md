Kernel

Минимальное ядро ОС на C и ассемблере для x86. Загружается через BIOS, работает в 32-битном Protected Mode. Написано с нуля для изучения системного программирования.
Что умеет

    Загрузчик (512 байт, Real Mode)

    Переход в Protected Mode (GDT, CR0)

    Ядро на C (freestanding)

    Драйвер VGA (текстовый режим 80x25)

    Вывод строк, очистка экрана, перенос строки, скролл

    IDT (Interrupt Descriptor Table)

    PIC (перепрограммирование на 0x20-0x2F)

    Драйвер клавиатуры (в процессе)

Структура

src/
boot.asm — загрузчик
kernel.asm — точка входа, вызов kernel_main
kernel.c — ядро, VGA-драйвер
idt.asm — загрузка IDT, заглушки обработчиков
idt.c — инициализация IDT
pic.c — перепрограммирование PIC
keyboard.c — драйвер клавиатуры
Сборка

Требуется кросс-компилятор i686-elf и NASM.

./build.sh на Linux
Запуск

qemu-system-x86_64 -drive file=bin/os.bin,format=raw
Как это работает

    BIOS загружает boot.bin по адресу 0x7C00.

    Загрузчик читает kernel.bin с диска через int 0x13.

    Переход в Protected Mode через GDT.

    Прыжок на kernel_main.

    Ядро инициализирует IDT, PIC, клавиатуру.

    Вывод текста через VGA-память по адресу 0xB8000.
